# Демо-сайт для DamDay

Онлайн-меню с корзиной: клиент выбирает блюда, нажимает «Отправить заказ в WhatsApp»,
и в WhatsApp приходит готовый заказ со списком, суммой, адресом и комментарием.
Весь сайт — один файл `index.html`.

## 1. Вписать свой номер WhatsApp (обязательно перед отправкой)
Пока в демо стоит номер-заглушка. Впишите **свой** номер, чтобы владелец, проверяя кнопку,
отправил тестовый заказ вам, а не в кафе.

1. Правой кнопкой по `index.html` → «Открыть с помощью» → «Блокнот».
2. Нажмите Ctrl + F и найдите `whatsapp: '77000000000'`.
3. Замените цифры на свой номер: только цифры, начиная с 7, без плюса и пробелов.
   Например, `whatsapp: '77011234567'`.
4. Ctrl + S, чтобы сохранить.

Номер кафе (+7 776 464 32 32) вписываем **только после согласия владельца**.

## 2. Посмотреть сайт у себя
Дважды щёлкните по `index.html`, сайт откроется в браузере. Чтобы увидеть, как он выглядит
на телефоне, нажмите F12, а затем Ctrl + Shift + M.

## 3. Выложить сайт в интернет (бесплатно)
1. Откройте **app.netlify.com/drop**.
2. Перетащите **всю папку `damday-demo`** с Рабочего стола в окно браузера.
3. Через несколько секунд появится ссылка вида `https://что-то-случайное.netlify.app`. Это и есть ваш сайт.
4. Netlify попросит зарегистрироваться (бесплатно, можно через Google), иначе сайт удалится через час.
   Зарегистрируйтесь, чтобы ссылка работала постоянно.
5. Откройте ссылку на своём телефоне и проверьте: добавьте блюдо, нажмите «Отправить заказ в WhatsApp».

## 4. Поменять цены или блюда
В `index.html` всё меню лежит в блоке `CONFIG` в начале скрипта. У каждого блюда есть
название (`name`), описание (`desc`), цена (`price`) и картинка-эмодзи (`emoji`).
Меняйте только текст внутри кавычек и числа.

## Перед показом владельцу
- Цены переписаны с фото меню в 2ГИС, кофе и напитки — с размытого фото, их стоит перепроверить.
- Внизу сайта есть надпись «Демо-версия сайта для DamDay», не убирайте её до договорённости.
- Сайт закрыт от поисковиков (noindex), его увидит только тот, кому вы дадите ссылку.
